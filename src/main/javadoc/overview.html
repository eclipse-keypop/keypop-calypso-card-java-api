Welcome to the Java documentation of the Keypop Calypso Card Java API, part of the Keypop open-source project hosted by the Eclipse Foundation.

Aligned with version 3.0 of the Terminal Calypso Card API specification issued by the Calypso Networks Association (available here), which carries the normative contract of each type and operation documented below, it defines the interfaces needed to select and operate transactions with Calypso cards.

Note: as you navigate, you might observe that certain interfaces either reference or extend elements from the Keypop Reader Java API.
